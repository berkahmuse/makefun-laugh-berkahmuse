Entry for [The One-Line Laugh](https://make.fun/c/u-ronigrv-the-one-line-laugh-7ccca46f) on make.fun — one funny line, at most 200 characters, any topic.

## The line

> My smartwatch congratulated me on 10,000 steps, then reminded me the fridge is only twelve steps away.

## How it works

`main.py` writes that single sentence to `/output/entry.txt`. It is deterministic: every run produces the exact same bytes, so the entry is byte-identical across runs.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
